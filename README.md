# 삼성생명 콘셉트 출근길 게임 (비공식 데모)

브라우저에서 플레이하는 20초 점프 러닝 게임입니다. 삼성생명과 무관한 비공식 프로토타입이며 공식 캐릭터 및 보험 상품은 포함하지 않습니다.

## 플레이 방법

- '출근 시작하기'를 클릭/터치해 시작합니다.
- PC: Space 또는 ↑ 키로 점프합니다.
- 모바일: 게임 화면 터치 또는 '점프 ↑' 버튼으로 점프합니다.
- 하트 3개를 지키며 20초를 완주하세요.

## GitHub Pages 배포

1. 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source**를 `Deploy from a branch`로 선택합니다.
3. **Branch**를 `main`, **Folder**를 `/(root)`로 설정하고 **Save**를 누릅니다.
4. 배포가 완료되면 https://suggestion22.github.io/test/ 에서 플레이할 수 있습니다.

별도의 다운로드나 빌드가 필요하지 않습니다. 파일 미리보기에서는 JavaScript 실행이 차단될 수 있으므로, 배포된 URL로 접속해 주세요.

## 테스트 범위

Chromium 데스크톱 및 모바일 화면 크기 기준으로 시작·타이머·점프·일시정지·재개를 확인했습니다. 실제 iOS Safari는 별도 검증이 필요합니다.
