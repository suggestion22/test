# BLUE GUARD RUN — 삼성생명 콘셉트 웹게임 (비공식)

[게임 플레이](https://suggestion22.github.io/test/)

브라우저에서 바로 플레이할 수 있는 **60초 횡스크롤 러닝 게임**입니다. 쿠키런 계열의 자동 러닝 방식에서 영감을 받았지만, 캐릭터와 코드는 독립적으로 제작되었습니다. 삼성생명 공식 콘텐츠가 아닙니다.

## 게임 기능

- 자동 달리기, **2단 점프**, **슬라이드**, 장애물 충돌
- 젤리 점수·콤보 배율, 실드·자석 아이템
- 3개의 하트, 60초 완주, 보너스 점수와 최고 기록 저장
- 배경 시간대 변화(아침 → 노을 → 저녁), 파티클, 간단한 효과음
- 모바일 전용 큰 터치 버튼과 데스크톱 키보드 조작, 일시정지 및 재시작
- HTML/CSS/JavaScript로 구성된 단일 정적 파일 (설치·빌드·서버 API 불필요)

## 조작법

| 동작 | PC | 모바일 |
| --- | --- | --- |
| 점프·2단 점프 | Space 또는 ↑ | 점프 버튼 |
| 슬라이드 | ↓ 또는 S | 슬라이드 버튼 |
| 일시정지 | P 또는 Esc | 우측 상단 Ⅱ |

## 배포

이 저장소의 `index.html`을 GitHub Pages (`main` / `(root)`)로 배포합니다.

## 검증 범위

Chromium에서 데스크톱(1440×900), 모바일(390×844), 소형 모바일(320×700) 화면의 시작·조작·일시정지·재개를 테스트했습니다. 점수/젤리/장애물/슬라이드/완주/재시작 로직 테스트도 수행했습니다. 실제 iPhone Safari 환경에서의 최종 검증은 별도로 필요합니다.

> **안내:** 이 저장소는 개인 제작 비공식 데모이며, 삼성생명 및 원본 게임 제작사의 공식 게임이나 홍보물이 아닙니다. 상표·캐릭터·리소스는 공식 에셋을 무단 사용하지 않습니다.
