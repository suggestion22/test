# BLUE GUARD RUN — 비공식 삼성생명 콘셉트 웹게임

자동으로 달리는 60초 횡스크롤 러닝 게임입니다. 삼성생명과 제휴하거나 공식 승인을 받은 게임이 아닌 개인 제작 프로토타입입니다. 기존 타사 게임의 코드·캐릭터·에셋을 복제하지 않았습니다.

## 바로 플레이
https://suggestion22.github.io/test/

## 조작
- PC: Space 또는 ↑ 점프(공중에서 한 번 더 누르면 2단 점프), ↓ 또는 S 슬라이드, P 또는 Esc 일시정지
- 모바일: 게임 아래 **점프**, **슬라이드** 버튼 또는 게임 화면 터치
- 60초 동안 장애물을 피하고 젤리/파워 아이템을 수집하세요.

## 기능
- 다층 패럴랙스 도시 배경 및 시간에 따른 하늘 색 변화
- 자동 달리기, 점프/2단 점프, 슬라이드, 충돌 및 피격 무적 시간
- 젤리 수집 콤보, 자석, 보호막, 하트 3개
- 점수·타이머·진행률·결과 화면·최고 점수 브라우저 저장
- 음향 켜기/끄기, 자동 일시정지, PC·모바일 반응형 UI
- 설치·빌드·서버 API 없이 `index.html` 한 파일로 실행 가능

## 배포
GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root)

## 검증 범위
Chromium에서 데스크톱(1280px), 모바일(390px), 소형 모바일(320px) 화면의 시작/점프/슬라이드/일시정지/결과/재시작 동작을 확인했습니다. iPhone Safari 실기기 동작은 별도 확인이 필요합니다.
