# BLUE RUN — 든든한 출근길

삼성생명 콘셉트로 제작된 **비공식** 브라우저 횡스크롤 러닝 게임입니다. 쿠키런과 같은 자동 달리기 장르의 일반적인 조작 방식을 참고하되, 캐릭터·그래픽·브랜딩 및 코드는 독립적으로 구성했습니다. 삼성생명과 공식 제휴·제작 관계가 없습니다.

## 게임 바로가기

**https://suggestion22.github.io/test/**

## 게임 방법

- **목표:** 별젤리를 모으고 장애물을 피해 45초 동안 달리기
- **모바일:** `JUMP` 탭(2단 점프 가능), `SLIDE` 누르고 있기
- **PC:** `Space` 또는 `↑` 점프 / `↓` 슬라이드 / `P` 또는 `Esc` 일시정지 / `M` 효과음 전환
- **아이템:** 보호막과 젤리 자석
- **점수:** 수집한 젤리 및 콤보, 완주 보너스. 최고 점수는 브라우저 로컬 저장소에 저장됩니다.

## 실행 및 배포

정적 `index.html` 한 파일로 구현되어 추가 빌드나 설치가 필요 없습니다. GitHub Pages의 `main` 브랜치 `/(root)`에서 제공됩니다. HTML 미리보기 화면은 JavaScript 실행을 막을 수 있어, 위의 공개 주소에서 플레이해야 합니다.
